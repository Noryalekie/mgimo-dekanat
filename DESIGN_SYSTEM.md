# 🏛️ MGIMO Diplomat.Core — UI/UX Design System & Architectural Blueprint
> **Цифровой деканат будущего** — концепт студенческой экосистемы нового поколения для студентов МГИМО.
> *Дисклеймер: Учебный концепт для конкурса MGIMO AI Hackathon. Не является официальным сервисом МГИМО МИД России.*

---

## 1. Концепция и философия бренда

### 1.1 Метафора и дух продукта
- **«Дипломатия в каждом пикселе»**: строгость, академическое достоинство, премиальная эстетика лучших международных институтов в сочетании со сверхбыстрым, отзывчивым UX уровня Apple, Linear и Vercel.
- **Главная идея**: избавить студента и сотрудников от бюрократического хаоса. Вся учеба, БРС, справки и регламенты сведены в прозрачный, интуитивный интерфейс с проактивным AI-советником («Дипломатический Атташе»).

### 1.2 Авторский герб / Эмблема
*Символ: «Дипломатический глобус и кристалл знаний» (Diplomatic Meridian & Knowledge Prism)*.
- **Векторная геометрия**:
  - Внешний контур: тонкая золотая арка меридиана (символ международных отношений и всемирного охвата).
  - Центр: многогранный кристалл лазурно-сапфирового градиента (символ ясного ума, многоязычия и аналитики).
  - Акцент: деликатная точка-звезда Полярной звезды в вершине (ориентир дипломатической службы).

### 3.1 Лейаут и навигационная сетка
```
+---------------------------------------------------------------+
| TOP HEADER (Mobile & Desktop)                                 |
| [Logo + Core]     [Jury Profile Switcher]   [Notifs] [Dark/Lt]|
+---------------------------------------------------------------+
| DESKTOP:                  | CONTENT CANVAS (Scrollable)       |
| Collapsible Sidebar       |                                   |
| - Главная                 |  * Header Banner & AI Insight     |
| - Расписание              |  * Metrics & BRS Radar Card       |
| - БРС & Оценки            |  * Today's Timeline / Schedule    |
| - Справки & Заявления     |  * Digital Services               |
| - AI-Ассистент деканата   |                                   |
| - Уведомления             |                                   |
| [Jury Quick Demo Bar]     |                                   |
+---------------------------------------------------------------+
| MOBILE BOTTOM TAB BAR (fixed, h-16, backdrop-blur-md)         |
| [Главная] [Расписание] [БРС] [Справки] [AI Чат]               |
+---------------------------------------------------------------+
```

### 3.2 Точки останова (Breakpoints)
- **Mobile (< 768px)**:
  - Скрыт боковой сайдбар.
  - Активен фиксированный нижний Tab Bar (`h-16 pb-safe`).
  - Быстрый переключатель профилей для жюри вынесен в компактный выпадающий чип в топ-баре.
  - Карточки на всю ширину с паддингом `px-4`.
- **Desktop (>= 1024px)**:
  - Фиксированный стеклянный сайдбар слева шириной `w-64` или `w-72`.
  - Модальные окна центрированы с мягким затемнением `backdrop-blur-md bg-slate-950/60`.
  - Двух- или трехколоночный грид дашборда (`grid-cols-12 gap-6`).

## 4. Спецификация ключевых экранов и пользовательских сценариев

### 4.1 Экран входа и демо-переключатель профилей для Жюри
**UX-задача**: Жюри должно в 1 клик переключаться между разными сценариями студента без ввода паролей.

#### Сценарии жюри (Preset Switcher):
1. **Алексей Волков (Отличник МЭО, 4 курс)**
   - Рейтинг БРС: `94.8 / 100` (A+, Повышенная стипендия им. Е.М. Примакова).
   - Расписание: Дипломатический протокол, Международные валютно-кредитные отношения.
   - Справки: 1 готова к выдаче (с QR-кодом для МИД РФ).
   - AI-советник: Предлагает тему диплома и подсказывает дедлайн предзащиты.
2. **София Романова (Зона академического риска, МЖ, 2 курс)**
   - Рейтинг БРС: `62.4 / 100` (Риск недопуска по «Второму иностранному языку: Испанский» — 58 баллов).
   - Алерты: 2 дня до рубежного коллоквиума.
   - AI-советник: Активирован режим спасения сессии с персональным планом закрытия долгов.
3. **Жан-Люк Дюбуа (Иностранный студент, МИЭП, 1 курс магистратуры)**
   - Язык интерфейса: Английский / Французский с переключением.
   - Справка: Заказ визового ходатайства и регистрация в общежитии на проспекте Вернадского.
4. **Екатерина Белова (Староста группы МП-04)**
   - Расширенный доступ: просмотр явки группы, уведомления от куратора курса.

**UI Компонент быстрого входа для жюри**:
- Плавающая или закрепленная плашка: `bg-amber-500/10 border border-amber-500/30 rounded-full px-3 py-1.5`.
- Содержит быстрые аватары и моментальный селектор роли.

### 4.2 Главный Дашборд Студента (Command Center)

#### Структура дашборда:
1. **Приветственный баннер с дипломатическим статусом**:
   - `Добро пожаловать, Алексей` • `Факультет МЭО • 4 курс • Группа 3`.
   - Проактивный инсайт от AI Деканата: *«До зачета по праву ВТО осталось 4 дня. Ваш БРС 42/50 — рекомендуем сдать эссе до пятницы»*.
2. **Виджет «Сегодня в МГИМО» (Next Up)**:
   - Ближайшая пара: *10:30 • Французский язык (дипломатическая переписка) • Ауд. 3144 (Новый корпус)*.
   - Live-бейдж: *«Идет сейчас»* или *«Через 25 мин»*.
   - Кнопка *«Маршрут по кампусу»* (интерактивная подсказка как пройти в аудиторию).
3. **Блок БРС и Академический прогресс (Quick Metrics)**:
   - 4 компактные карточки:
     - Текущий средний балл: `94.8` (Зеленый/Золотой бейдж A+).
     - Закрыто зачетных единиц (ECTS): `214 / 240`.
     - Пропуски: `2 часа` (98.5% посещаемости).
     - Заказ справок в процессе: `1 активная заявка`.
4. **Виджет быстрых действий (Action Bar)**:
   - Заказать справку в 1 клик.
   - Записаться на прием к замдекана.
   - Спросить AI-Ассистента по регламенту пересдачи.
   - Показать студенческий билет / цифровой пропуск (QR).

### 4.3 Модуль «Расписание занятий»

#### Особенности и UX:
- **Переключатель представлений**: `Сегодня` / `Вся неделя` / `Сессия (Экзамены)`.
- **Индикаторы изменений в реальном времени**:
  - Бейдж `Замена аудитории`: ауд. 4118 -> Конференц-зал №2 (красно-оранжевый пульсирующий бейдж).
  - Бейдж `Дистанционно`: ссылка на подключение в 1 клик.
  - Бейдж `Перенос`: время сдвинуто по согласованию с кафедрой.
- **Карточка пары**:
  - Временной слот: `09:00 — 10:20`, номер пары (1 пара).
  - Название дисциплины + Тип (Лекция, Семинар, Языковая группа).
  - Преподаватель (ФИО, ученая степень, должность).
  - Локация (Корпус, этаж, аудитория) с кликом для показа подсказки навигации по кампусу на Вернадского.
  - Прикрепленные материалы (ссылка на ридер или СДО).

### 4.4 Модуль «Успеваемость и БРС» (Балльно-рейтинговая система)

#### Архитектура экрана:
1. **Сводная шкала студента**:
   - Общий суммарный балл и прогноз итоговой оценки (`A: 90-100`, `B: 82-89`, `C: 75-81`, `D: 67-74`, `E: 60-66`, `F: <60 Пересдача`).
2. **Радар рисков (Risk Early-Warning System)**:
   - Цветовая категоризация дисциплин:
     - 🟢 **Безопасная зона (85-100 баллов)**: автомат гарантирован.
     - 🟡 **Зона внимания (70-84 балла)**: нужно добрать баллы на семинарах.
     - 🔴 **Зона критического риска (<70 баллов)**: риск недопуска к экзамену. Показывает, сколько баллов не хватает до порога 60.
3. **Детальная раскладка по предметам**:
   - Аккордеон с разбивкой:
     - Работа на семинарах (макс. 30 баллов)
     - Контрольные / Коллоквиумы (макс. 30 баллов)
     - Посещаемость (макс. 10 баллов)
     - Итоговый экзамен (макс. 30 баллов)
   - Кнопка *«Апелляция / Вопрос преподавателю»*.

### 4.5 Модуль «Сервис справок и заявлений» (Paperless Dean's Office)

#### Каталог доступных документов:
1. Справка об обучении (по месту требования, для военкомата, посольства/визы).
2. Справка с оценками (Academic Transcript на русском и английском).
3. Заявление на выбор второго/третьего иностранного языка.
4. Заявление на утверждение темы ВКР и научного руководителя.
5. Заявление на материальную помощь или академический отпуск.

#### UX-трекер статуса заказа (Live Timeline Component):
```
[●] Подано онлайн (09 ноя, 11:42)
  │
[●] Принято канцелярией факультета (09 ноя, 14:10)
  │
[●] На электронной подписи декана (В процессе, ожидание ~2 ч)
  │
[○] Готово к выдаче / Скачать с ЭЦП (Пункт: Кабинет 3012 или PDF с QR-валидатором)
```
- Для каждой готовой справки генерируется:
  - Официальный предпросмотр документа.
  - QR-код для верификации подлинности документа государственными органами и посольствами.
  - Кнопка «Скачать официальный PDF с синей печатью ЭЦП».

### 4.7 AI-Ассистент деканата («Атташе / Diplomat AI»)

#### Возможности ассистента:
- Ответы на вопросы по Положению об организации учебного процесса в МГИМО (БРС, уважительные причины пропусков, перевод на бюджет).

- Быстрые подсказки-чипы (Prompts):
  - *«Как заказать справку для посольства?»*

  - *«Сколько баллов нужно для автомата по экономике?»*
  - *«Покажи расписание на завтра»*.
