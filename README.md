## 🌟 Стиль и эстетика (Vertix Bento Grid)
Проект разработан в точном соответствии с референсом **Vertix style**:
- **Цветовая гамма**: Мягкий фарфоровый светлый фон (`#F4F6F9`) и глубокий сапфировый ночной режим (`#0A131F`).
- **Floating Pills**: Парящие капсулы навигации с эффектом размытия `backdrop-blur-md`, мягкими тенями и элегантными границами.
- **Left Floating Island**: Отдельный парящий вертикальный остров иконок слева (на мобильных устройствах автоматически трансформируется в эргономичный нижний Tab Bar).
- **Signature Accent Card**: Градиентная акцентная карточка успеваемости и статуса дипломата (в стиле яркой акцентной карточки Vertix).
- **Авторский логотип**: «DIPLOMAT CORE» со стилизованной векторной эмблемой «Дипломатический меридиан и кристалл знаний» (без использования официальной символики МГИМО).
- **Официальный дисклеймер хакатона**: Закреплен в подвале страницы и в меню жюри.

## 🚀 Быстрый запуск

### Вариант 1: Через скрипт запуска
```bash
./run.sh
```
Затем откройте в браузере: **`http://localhost:3000`**

### Вариант 2: Прямой запуск через Python
```bash
python3 -m http.server 3000
```
Затем откройте в браузере: **`http://localhost:3000`**

### Вариант 3: Открытие без веб-сервера
Просто откройте файл `index.html` двойным кликом в любом браузере (Chrome, Safari, Arc, Firefox, Edge).

## ⚡ Ключевые интерактивные модули

### 1. 📅 Интерактивное расписание
- Вкладки: **«Сегодня»**, **«Вся неделя»**, **«Сессия (Экзамены)»**.
- Фильтры пар: Лекции, Семинары, Иностранные языки.
- Заметный бейдж **«Идет сейчас»** с пульсирующей анимацией.
- Заметный бейдж **«Замена аудитории»** (ауд. 4118 → Зал Дипломатии).
- Кнопка **«Маршрут»**: открывает интерактивную подсказку по навигации в кампусе МГИМО на Вернадского.

### 2. 📊 Балльно-рейтинговая система (БРС) и «Радар рисков»
- Рейтинг (0–100) и международная шкала ECTS (A, B, C, D, E, F).
- Цветовая категоризация: Безопасная зона (85+), Зона внимания (70–84), Критический риск (<70).
- **Интерактивный калькулятор баллов до автомата**: живые слайдеры (семинары, контрольные, посещаемость, экзамен) с моментальным расчетом: сколько баллов не хватает до 90 (автомат) или 60 (зачет).

### 3. 📑 Онлайн-заказ справок и Официальный бланк
- Заказ справки онлайн: справка об обучении, академический транскрипт с оценками, справка в военкомат, визовое ходатайство.
- **Живой 4-шаговый трекер**: `Подано -> В канцелярии -> На подписи -> Выдано`.
- **Просмотр бланка**: высокоточная цифровая копия официальной справки МГИМО МИД России с синей печатью деканата, отметкой ЭЦП, валидационным QR-кодом и функцией печати/PDF (`Cmd+P`).

### 4. 🤖 AI-Ассистент («Дипломатический Атташе / AI-Декан»)
- Персональный диалоговый ассистент, знающий Устав МГИМО, Положение о БРС, правила ликвидации задолженностей и расположение кафедр.
- Быстрые чипы частых вопросов.
- Контекстно-зависимые рекомендации (например, для Софии — персональный план закрытия долга по испанскому языку).

### 5. 🎫 Цифровой кампусный пропуск
- Электронный студенческий билет с фото, шифром и симуляцией бесконтактного прохода (NFC / RFID) через турникеты главного входа.

### 6. 🌓 Темы и Адаптивность
- Переключатель тем (Светлая / Темная) с сохранением в `localStorage`.
- Мобильная адаптивность: плавное масштабирование от 360px до 4K дисплеев.
